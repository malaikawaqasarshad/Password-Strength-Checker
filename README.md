# Password-Strength-Checker
This password strength checker analyses variation of characters and length to determine the strength of a given password.

## Features

* Checks password length
* Detects uppercase and lowercase letters
* Checks for numbers
* Checks for special characters
* Gives a strength rating

### Installation

Clone the repository:

git clone https://github.com/malaikawaqasarshad/password-strength-checker.git

Move into the project folder:

cd password-strength-checker

Then follow the setup instructions for the language/framework you're using.

## Usage

Run the application and enter a password into the password field.

The checker will analyse the password and provide a strength rating along with suggestions for improvement.

## 📋 Strength Criteria

The checker evaluates things such as:

| Criteria           | Example                |
| ------------------ | ---------------------- |
| Length             | At least 8 characters |
| Uppercase          | `A-Z`                  |
| Lowercase          | `a-z`                  |
| Numbers            | `0-9`                  |
| Special characters | `! @ # $ %`            |

> **Note:** This is an educational password-strength checker, not a guarantee that a password is secure. Password strength depends on more than just character types and length.
